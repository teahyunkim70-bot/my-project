# report-writing — 지침·템플릿 기반 보고서 작성 (HWPX)

## 언제 쓰나
- 사용자가 사업계획, 로드맵, 추진계획, 정책·상황·검토·회의·행사·업무보고, 보도자료를 쓰거나 다듬어 달라고 할 때
- "N번 템플릿에 맞게"라고 번호를 말할 때 (번호는 `templates/` 파일 앞 숫자)
- 결과물은 한글에서 여는 `.hwpx`이다.

## 작업 순서
1. **지침 로드**: `reference/rules.md`(작성 규칙 요약)를 읽는다. 상세는 `reference/guide.md`.
2. **유형·템플릿 결정**
   | 번호 | 파일 | 용도 |
   |---|---|---|
   | 1~8 | `templates/1_정책보고서` … `8_보도자료` (.hwpx) | 1~2쪽 단문 보고서 (정책, 상황, 검토, 회의개최, 회의결과, 행사, 업무보고, 보도자료) |
   | 9 | `9_결식아동_급식지원_개선계획_템플릿.hwp` | **종합 계획안**: 표지(결재란) → 요약 1쪽 → 목차 → Ⅰ 추진배경 → Ⅱ 사업개요·현황 → Ⅲ 사업분석 → Ⅳ 단계별 추진계획 → Ⅴ 세부추진계획(AS-IS/TO-BE) → Ⅵ 추진일정(간트표) |
   | 10, 11 | 보드게임 페스티벌, 시정 업무토론 계획 (.hwp) | 행사·토론 계획 참고용 |
   번호를 주지 않으면 분량과 성격에 맞게 고르고, 고른 이유를 한 줄로 알린다.
3. **원자료 수집**: 사용자가 가리킨 PDF·HWP·HWPX를 읽는다. 사실(수치, 날짜, 고유명사)은 원자료에서만 가져오고 지어내지 않는다.
   - HWP/HWPX: `npx --yes --package kordoc --package pdfjs-dist kordoc <파일>` (Markdown 출력)
   - PDF: `pip install pymupdf` 후 `fitz`로 텍스트 추출. 표·그림은 `get_pixmap(dpi=60~70).save()`로 이미지화해 Read로 확인한다. 이 환경에는 `pdftoppm`이 없다.
4. **내용 구성**: 규칙(두괄식, 제목 20자 이내, 개조식 `~함/~했음`, 한 문장 2줄 이내, 날짜 `2026. 9. 1.`, 금액·시간 표기)에 맞춰 재구성한다. 9번 구조에서 원자료에 근거가 없는 항목은 억지로 채우지 말고 줄이거나 `(확정 후 기재)`로 둔다.
5. **HWPX 생성**
   - 1~8번류(단문): `scripts/hwpx_lib.py`의 `save(경로, ops)`
   - 9번류(종합): `scripts/hwpx_ext.py`를 `from hwpx_ext import *` 하고 `gen.save(경로, ops)`
   - 예시: `examples/ostreet_plan_9.py`, `examples/roadmap_9.py` (복사해서 `ops` 내용만 교체)
   ```bash
   py .claude/skills/report-writing/examples/roadmap_9.py "출력경로.hwpx"
   ```
6. **검증**: kordoc으로 생성한 HWPX를 다시 읽어 구조를 확인한다(`npx ... kordoc 출력.hwpx`). 한글에서 열어 보지 못했다면 그렇게 보고한다.
7. **보고**: 만든 파일 링크, 원문과 맞지 않거나 합계가 안 맞는 수치, 근거가 없어 비워 둔 항목을 알린다.

## ops 문법 (hwpx_lib / hwpx_ext)
| op | 의미 | 서식 |
|---|---|---|
| `('title', t)` | 제목 상자 | HY헤드라인M 24pt, 연한 바다색, 0.3mm |
| `('overview', t)` | 개요 상자 | 중고딕 15pt, 위쪽 점선 |
| `('big', t)` | `□` 큰 제목 | HY헤드라인M 16pt |
| `('sm', t)` | 작은 제목 | 휴먼명조 16pt 굵게 |
| `('o', t)` `('d', t)` `('dot', t)` | `○` `-` `•` 항목 | 휴먼명조 15pt, 칸 들여쓰기 |
| `('n', t)` | `※` 참고 | 중고딕 12pt |
| `('plain', t)` `('right', t)` `('gap',)` | 본문, 가운데, 빈 줄 | |
| `('table', rows, widths)` | 표 | 머리행·첫 열 음영 |
| (ext) `approval, ctitle, csub, corg, space` | 표지 | |
| (ext) `sumsub, tochead, toc` | 요약·목차 | 쪽나눔 포함 |
| (ext) `h1pb, h1` | Ⅰ~Ⅶ 대제목 | h1pb는 새 쪽에서 시작 |
| (ext) `conclude` | ◈⇨ 결론 박스 | |
| (ext) `grid, grid_nohead, gantt` | 셀 안 줄바꿈(`\n`) 표, 간트표 | `gantt`는 `marks={(행,열)}` 음영 |

## 지켜야 할 것
- 새로 지어낸 사실 금지. 원문 수치가 서로 안 맞으면 원문대로 쓰고 사용자에게 알린다.
- 결재란 이름은 원자료에 있을 때만 넣는다.
- 목차 쪽번호는 한글에서 쪽수를 확인한 뒤에야 넣을 수 있으므로 비워 둔다.
- 글꼴(HY헤드라인M, 휴먼명조, HY중고딕)은 한컴오피스에 설치된 글꼴을 가정한다.
- 이 템플릿 `.hwp`(9~11번)는 이진 파일이라 직접 편집하지 않는다. 같은 구성을 HWPX로 새로 만든다.
