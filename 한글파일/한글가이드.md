# 보고서 작성 한글 가이드

> 출처: 인천광역시 『일하는 방식 개선을 위한 보고서 품질향상 매뉴얼』 (OCR 원문을 교정·정리한 요약본)
> 보고서를 작성할 때 이 문서의 원칙과 서식을 따른다.

---

## 1. 작성 원칙

### 1-1. 3가지 핵심가치
| 가치 | 내용 |
|---|---|
| **목적성** | 보고 사유(지시, 언론 제기, 민원 등)와 결재권자에게 요청하는 바를 명시한다. 시정 방향·전략과의 연계를 밝힌다. |
| **핵심내용** | 아는 정보를 나열하지 않는다. 목적·방향·대책 등 가장 중요한 내용을 앞에 요약하고 덜 중요한 내용은 뒤에 둔다. 중요한 내용이 뒤에 오면 "특히", "더구나"로 주의를 끈다. |
| **실용성** | 실천 가능하고 구체적인 방안을 제시한다. 결재권자가 "그래서 어떻게 해야 하나?"라고 묻지 않도록 조치사항을 분명히 쓴다. |

### 1-2. 결재권자(독자) 중심으로 쓴다
- 내가 일한 순서가 아니라 **결재권자가 알고 싶은 순서**로 쓴다.
- 보고자의 이해관계나 편견을 배제하고, **사실과 의견을 구분**해서 전달한다.
- 쉬운 일상용어를 쓴다. 서체, 글자 크기, 레이아웃도 결재권자에게 맞춘다.
- 민원 안내문은 시의 입장이 아니라 민원인 입장에서, 보도자료는 언론의 뉴스 가치와 독자의 편익 관점에서 쓴다.
- 보고서에는 결과뿐 아니라 과정과 경험도 남겨 후임자의 참고자료가 되게 한다.

### 1-3. 길어도 2페이지를 넘기지 않는다
- 방대한 내용도 요지는 **1페이지(One Page Report)** 로 압축한다. 나머지는 붙임으로 보완한다.
- 요지에는 반드시 **용건(결론) + 근거 + 핵심 메시지**를 넣는다.
- **두괄식**: 용건(주장) → 근거/이유 순서로 쓴다. (미괄식은 지양)
- 추상적으로 쓰지 말고 예시와 사례로 구체화한다.

### 1-4. 카테고리로 분류해 구조화한다
- 상위·중위·하위 위계에 따라 같은 속성의 정보를 묶는다. (오일장식 나열이 아니라 대형마트식 진열)
- 개조식은 문장 앞에 부호를 붙이고 조사·종결어미를 최대한 줄인 **키워드 중심 문장**이다.
- 단순 분절한 유사 개조식을 주의하고, 지나치게 쪼개지 않는다.

### 1-5. 직관적이고 구체적으로 쓴다
- 피할 것: 추상화, 관념화, 보편화, 모호함.
- 지킬 것: **6하원칙, 고유명사, 숫자, 오감 표현**.
  - 예) "양생중, 주의하세요" ✕ → "양생중, 밟지 마세요" ○
- "설명하지 말고 보여줘라(Show, Don't Tell)": 사례·통계·비유·인용을 활용한다.
- **지식의 저주**에 주의한다. 보고자가 아는 만큼 결재권자도 알 것이라 가정하지 말고 역지사지한다.
- 표·그래프만 던지지 말고, 계산기 없이도 알 수 있게 핵심 포인트를 풀어 쓴다.

## 2. 작성 절차

1. **보고 목표 설정·구상**: 핵심 이슈, 보고 배경, 독자, 사용처, 보고 시기(결재 소요 시간 포함)를 정하고 전체 틀(분량, 문체)을 구상한다.
2. **자료 수집·분석**: 공개 자료, 과거 사례, 관련 부서 담당자 자료를 활용한다. 적합성, 출처 신뢰성, 정확성을 확인하고, 완전히 이해한 자료만 쓴다. (전문가 수준으로 이해하고, 비전문가도 알도록 쉽게 쓴다.)
3. **작성**: 목차 → 주요 내용 → 문장·표·그림으로 초안을 만들고, 수요자 입장에서 수정·보완한다.
   - 수요자가 궁금한 점을 해소했는가?
   - 객관적이고 설득력이 있는가?
   - 불명확한 표현은 없는가?
4. **보고 및 사후조치**: 제목, 작성일자, 소속 등 필수항목을 점검한다. 결재 후 지시사항을 등록하고 일정에 따라 이행을 확인한다. (후속 조치가 보고보다 중요)

## 3. 전개 방식과 표준서식

### 3-1. 전개 방식
- **제목**: 내용·취지·성격이 드러나게 **20자 이내**로 압축한다. 수식어와 조사는 과감히 생략한다.
  - 예) 「7월 태풍·호우로 62명, 2조 625억 원 피해」
- **개요**: 목적과 경위(배경)를 간략히 정리한다.
- **본문**: 가급적 6하원칙으로 쓴다. 개조식은 **한 문장 2줄 이내(최대 3줄)**, "~했음", "~할 예정임"처럼 시제를 분명히 한다. 중복을 피하고 능동형을 쓰며 **한 문단에 한 초점**만 둔다.
- **결론**: 실천 가능하고 구체적인 제안, 향후 조치사항으로 쓴다.

### 3-2. 서식 규격
| 항목 | 규정 |
|---|---|
| 용지 | A4 세로, 여백 위 15mm / 아래 10mm / 좌·우 20mm, 머리말·꼬리말 10mm |
| 문서 제목 | HY헤드라인M **24pt**, 제목상자(연한 바다색 바탕, 테두리 0.3mm) |
| 큰 제목(□) | HY헤드라인M **16pt**, 줄간격 180% (문단 위 15pt) |
| 작은 제목 | 휴먼명조 16pt, 줄간격 180%, 진하게 (문단 위 10pt) |
| 개요 상자 | 중고딕 15pt, 줄간격 160%, 위쪽 0.12mm 점선, 바탕 없음 (취지가 본문에 있으면 생략) |
| 본문 | 휴먼명조 **15pt**, 줄간격 160% (문단 위 5pt) |
| 참고사항(※) | 중고딕 12~13pt, 줄간격 130% |
| 표 안 글자 | 중고딕·맑은고딕 12~13pt, 셀 좌우 여백 3pt 정도 |
| 강조 | 명사 위주 핵심 키워드만 **굵게** (동사·한자어에는 자제) |
| 번호 체계 | 보고서 내용에 따라 번호(1, 가, 1), 가) …) 또는 도형(□, ○, -, •) 중 선택 |

- **항목 부호 위치**: 하위 항목은 상위 항목보다 **1칸씩 오른쪽**으로 들여쓴다.
  ```
  □ 큰 항목 (헤드라인M 16pt)
   ○ 중간 항목 (휴먼명조 15pt, 1칸 들여쓰기)
     - 세부 항목 (2칸 들여쓰기)
       • 부연 (3칸 들여쓰기)
         ※ 참고 (중고딕 12pt)
  ```
- **날짜**: `2019. 8. 15.` (연·월·일 글자 생략, 온점 사용)
- **시간**: 24시 기준 `15:20` (시·분 생략, 쌍점 사용)
- **금액**: `금113,560원(금일십일만삼천오백육십원)`
- **추진 주안점**: 서식 틀보다 내용에 중점을 둔다. **1건 1매** 원칙이고, 내용이 많으면 2~3매 이내로 줄이고 나머지는 참고자료로 첨부한다. 대내외 보고·시행 문서는 표준·종합보고서 서식을 준용하되 자율적으로 작성한다.

## 4. 보고 전 점검사항 (체크리스트)

- [ ] **목적**: 보고 목적이 분명하고 내용 전체가 그 취지에 부합하는가?
- [ ] **정확성**: 이해관계·선입견을 배제하고 사실을 확인했는가? 출처가 분명한가? 타 부서·과거 사례도 검토했는가?
- [ ] **간결성**: 육하원칙으로 썼는가? "극히", "매우" 같은 부사와 과장을 줄였는가? 서술형 개조식(`~하였음`)인가?
- [ ] **이해 용이성**: 전문용어·한자어·외래어를 줄이고 필요하면 괄호로 풀었는가? 사례·그래프를 활용했는가?
- [ ] **완결성**: 추가 보고 없이 이 보고서만으로 의사결정이 가능한가? 결재권자의 예상 질문에 답이 있는가?
- [ ] **시점**: 사안 성격과 결재권자 상황을 고려한 최적의 시점인가?

## 5. 유형별 보고서

| 유형 | 정의 | 주요 구성 |
|---|---|---|
| **정책보고서** | 정책 관련 상황·문제점을 인식하고 의사결정하도록 사실과 대책을 제시 | 제목 → 보고목적 → 사업개요(배경·목적) → 현황 및 문제점(원인분석, 타 시·도 사례) → 개선방안(기대효과) → 추진계획 → 행정사항 |
| **상황보고서** | 특정 상황·추진동향을 **신속·정확·간결**하게 전달 | 제목 → 보고목적 → 사업개요 → 현황(추진상황) → 해결방안 → 향후계획 |
| **검토보고서** | 용역·계약·사업·요청 등의 검토 내용과 결과를 설명 | 제목 → 보고목적 → 사업개요 → 추진배경 → 검토내용(1안/2안) → 검토결과 → 향후계획 |
| **회의개최보고서** | 정보공유·의견수렴·의사결정 회의의 개최 계획 | 제목 → 회의개요(일시·장소·참석자·목적) → 회의안건 → 진행순서 → 행정사항 |
| **회의결과보고서** | 회의 결과를 정확히 전달 (녹취록이 아님) | 제목 → 회의개요 → 회의결과(안건별 결론·참석자별 주요 의견) → 향후계획 → 붙임(회의록) |
| **행사보고서** | 행사 기획·준비·진행용, 행사주재자 맞춤형 | 제목 → 행사목적 → 행사개요 → 행사내용 → 진행순서(시간·내용·비고) → 행정사항 |
| **업무보고(메모보고)** | 업무 진행 과정을 알림 | 제목 → 보고목적 → 사업개요 → 추진계획 → 기대효과 → 행정사항 |
| **보도자료** | 시의 입장을 언론을 통해 시민에게 알림 | 주제목 → 부제목 → 리드문 → 본문 → 인용 → 첨부자료 |

### 유형별 핵심 주의점
- **정책/검토**: 특정 집단·관점이 아니라 **전체 입장에서 균형 있게** 분석한다. 1차 원인만 찾지 말고 **원인의 원인**까지 파악해 실효성 있는 해법을 제시한다.
- **상황**: 결론을 먼저 쓰고 경제적 어휘로 핵심만 쓴다. 제목에 "동향·현황" 같은 포괄적 표현을 지양하고 구체적으로 쓴다.
  - 예) 「금속연맹 최근동향」 ✕ → 「금속연맹, 전국 동시 시한부 파업 및 집회 추진」 ○
- **회의개최**: 회의로 얻을 효과를 명시하고, 본문과 참고자료를 구분하며, 참석자의 평균 수준에 맞춘다. 목적별 필수요소는 다음과 같다.
  - 정보공유: 목적, 내용, 활용방안, 보안
  - 의견수렴: 배경, 논의 현황, 쟁점과 논거
  - 의사결정: 결정대상 쟁점과 논거, 이해당사자 입장
- **회의결과**: 발언 순서가 아니라 **주제별·발언자별**로 요약한다. 결론과 조치사항을 명시하고 상세 발언록은 첨부한다.
- **행사**: 기획 의도(취지, 배경, 시기, 공개 여부, 전달 메시지)가 부각되게 쓴다. 참고자료·말씀자료·참석자 프로필·예상 발언은 **첨부**로 돌린다.
- **업무(메모)보고**: 본문은 한 화면(12pt) 분량으로 쓰고 세부 내용은 첨부한다.
  - 메모보고: 방침이 필요 없는 문서 (회의·행사 결과, 자료 취합, 정보 공유)
  - 온나라 결재: 방침·협조가 필요한 문서 (정책 사업 결정, 지출, 근거 마련)
  - 서식 상단에 대외공개 여부, 보도자료 제공 여부를 반드시 체크한다.

## 6. 보도자료 작성법

### 6-1. 제목
- 제목이 반이다. **15자 내외(20자 이내)**, 눈길을 끌면서 핵심을 전한다.
- **주제목은 카피**(비유, 리듬), **부제목은 핵심 요약**으로 역할을 나눈다.
- 제목과 본문 내용이 일치해야 하고, 적극적인 행정 자세를 보여준다.
- 주어가 없고 길면 부제를 활용한다.
- 시민 관심 행사는 튀는 카피를 쓴다.

| Before | After |
|---|---|
| 인천시, 산림분야 정부합동평가 전국 우수기관 · 인천둘레길 · 명상숲 사업 전국 최고로 꼽혀 | 인천시 올해 산림행정, 골고루 높은 평가 받아 |
| 한겨울 새로운 즐거움 윈터마켓 개최 | 겨울 속 따뜻한 즐거움! 가족, 친구, 연인과 함께! |

### 6-2. 본문
- **두괄식**: 핵심·새 소식을 리드문(첫 문단)에 담고 배경·설명·경과는 뒤에 둔다.
- 리드문에 **구체적 내용**(누가, 무엇을, 얼마나)을 넣고, 제목의 내용을 반영한다.
- 둘째 문단은 리드문이 약속한 구체 내역을 담는다. (예: 12개 기관상의 내역)
- "이 시점에 왜 뉴스인가"(계기)를 밝힌다.
- 문장은 복문·장문이 아니라 **단문**으로 쓴다. 문단은 3~4줄, 한 문장에 한 주제만 담는다.
- 형용사·부사·미사여구와 전문용어를 배제하고, 객관적 자료 중심으로 말하듯 쉽게 쓴다.
- 홍보할 목적과 방향이 분명해야 한다. (홍보 논리가 성립하지 않는 사안은 보도 대상이 아님)

### 6-3. 주의사항
- "밝혔다", "말했다"처럼 기자가 쓴 듯한 표현을 쓰지 말고 **스스로를 화자**로 삼는다.
- 발언을 인용할 때는 꼭 전달할 주장만 골라 **실명**을 밝힌다.
- 보도 희망일, 작성자, 연락처, 홈페이지 주소를 명기한다.
- 사진·도표·그래픽 등 시각 자료를 첨부한다.
- 소리 내어 읽으며 퇴고하고 타인에게 교정을 부탁한다.

---

## 7. 한눈에 보는 요약 (Quick Checklist)

1. 제목은 20자 이내로 핵심을 담았는가?
2. 첫 문단에 결론(용건)과 요청사항이 있는가?
3. 1~2페이지 이내이고, 요지는 한 장으로 요약했는가?
4. 카테고리로 구조화했고, 한 문장이 2줄(최대 3줄)을 넘지 않는가?
5. 숫자·고유명사·사례로 구체화했는가?
6. 사실과 의견을 구분했고 출처가 분명한가?
7. 결재권자가 취할 조치(그래서 무엇을 해야 하는가)를 명시했는가?
8. 시제(`~했음`, `~할 예정임`), 날짜·시간·금액 표기가 규정에 맞는가?
9. 세부 자료는 붙임·참고로 분리했는가?

## 8. 참고 사례에서 배울 점

- **결식아동 급식지원 사업 개선계획**: 요약본 1장 + SWOT 분석(강점·약점·기회·위협) + 단계별 추진계획 + AS-IS/TO-BE 비교표 + 추진일정표 + 참고자료의 구조가 좋은 모범이다.
- **인천 보드게임 페스티벌 추진계획**: 요약(추진배경, 행사개요, 주요내용, 향후계획)과 상세본으로 구성하고, 배치도·참가기업표·대회일정표 등 시각 자료를 활용했다.
- **시정 분야별 업무토론 계획**: 추진배경 및 방향 → 추진개요(주재·일시·장소·대상·방식·절차) → 분야·주제·주관부서 표 → 행정(협조)사항으로 구성하고, 분야별 실행계획 양식을 붙임으로 제공했다.

> 이 매뉴얼은 대통령 비서실 「보고서 품질향상 연구팀」의 『보고서 작성 매뉴얼』(2005.12.) 일부를 참고해 작성된 것이다.
